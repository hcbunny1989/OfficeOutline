# 图表解析元素与属性说明

更新时间：2026-05-19

本文只说明当前工程已经能从 `.docx`、`.pptx`、`.xlsx` 中解析并输出的 Office 自建图表信息。这里的“Office 自建图表”指 Word、PowerPoint、Excel 三件套里插入的饼图、折线图、柱状图、雷达图等 OOXML 图表，不包含截图、普通图片或第三方渲染后的位图。

当前输出是 Markdown 文件中的 XML/HTML 风格标签。每个标签都会带 `tag` 属性；属性为空时通常不会输出。因此，某个属性没有出现，一般只能说明源文件对应位置没有直接提供该值，不能简单理解为该属性为 `false` 或 `0`。

## 图表输出层级

一个完整图表大致会输出成以下结构：

```xml
<chart tag="chart" chartType="lineChart" title="销售额">
  <chart_source tag="chart_source" type="embedded_xlsx">
    <table tag="table" role="chart_data">...</table>
  </chart_source>
  <chart_legend tag="chart_legend">...</chart_legend>
  <chart_axis tag="chart_axis" type="catAx" />
  <chart_axis tag="chart_axis" type="valAx" />
  <chart_data_labels tag="chart_data_labels" />
  <chart_series tag="chart_series">
    <chart_point tag="chart_point" />
  </chart_series>
</chart>
```

不是每种图表都会有所有子元素。例如饼图通常没有坐标轴；没有图例的图表不会输出 `chart_legend`；数据源是外部文件时，可能只有 `chart_source` 关系信息而没有展开的 `chart_data` 表格。

更贴近实际输出的树状嵌套关系如下。`?` 表示可选，`*` 表示可能出现多个，`+` 表示至少一个或多个。

```text
chart
├── chart_source?                         图表数据源关系
│   └── table? role="chart_data"           内嵌 xlsx 数据表；仅 embedded_xlsx 且可读取时出现
│       └── table_row*
│           └── table_cell*
│               ├── formula?
│               └── plain_text?
├── chart_legend?                          图例整体
│   └── chart_legend_entry*                单个图例项
├── chart_axis*                            坐标轴；饼图等无坐标轴图表通常没有
├── chart_data_labels*                     数据标签设置；可同时有图表级和系列级
└── chart_series+                          数据系列
    └── chart_point*                       系列中的单个数据点
```

不同文件类型的 `chart` 外层位置不完全一样：

```text
docx: document
      └── part
          └── paragraph
              └── text_run
                  └── drawing_object
                      └── chart

pptx: document
      └── part
          └── shape
              └── chart

xlsx: document
      ├── table*
      └── drawing_object*
          └── shape
              └── chart
```

## 图表元素说明

| 元素 | 输出标签 | 作用说明 |
|---|---|---|
| 图表 | `chart` | 一个完整的 Office 图表对象。它是后续数据源、图例、坐标轴、数据标签、系列和数据点的根容器；同时保存图表类型、标题、图表文件路径以及在页面/幻灯片/工作表上的位置尺寸。 |
| 图表数据源 | `chart_source` | 图表背后的数据来源。Office 图表通常由一个内嵌工作簿或外部工作簿提供数据；该元素描述这个数据源和图表之间的关系。 |
| 图表数据表 | `table role="chart_data"` | 当图表带有内嵌 xlsx 数据时，工程会把这个内嵌工作簿中的工作表按普通表格输出，并用 `role="chart_data"` 标明它是图表数据，不是正文里的普通表格。 |
| 图例 | `chart_legend` | 图表旁边用于解释颜色、线条或切片含义的图例区域。它描述图例整体的位置、覆盖方式、文本颜色和手动布局。 |
| 图例项 | `chart_legend_entry` | 图例中的单个条目。折线图、柱状图等通常每个系列对应一个图例项；饼图、圆环图通常每个切片，也就是每个数据点，对应一个图例项。 |
| 坐标轴 | `chart_axis` | 图表中的轴。常见的是横向类别轴和纵向数值轴；3D 或特殊图表还可能有日期轴、系列轴。饼图这类没有坐标系的图表通常不输出坐标轴。 |
| 数据标签 | `chart_data_labels` | 显示在柱子、折线点、饼图切片等图形旁边的文字标签设置。它描述是否显示数值、分类名、系列名、百分比等，不代表数据点本身。 |
| 系列 | `chart_series` | 一组被一起绘制的数据点，是图表的核心数据组织单位。在折线图中，一个系列通常是一条线；在柱状图中，一个系列通常是一组同色柱子；在饼图中，通常只有一个系列，这个系列里的每个点就是一个切片。 |
| 数据点 | `chart_point` | 系列中的单个数据项。它通常对应折线图上的一个点、柱状图中的一根柱子、饼图中的一个切片。 |

## 通用属性

| 属性 | 出现位置 | 说明 |
|---|---|---|
| `tag` | 所有图表相关标签 | 输出标签名的重复标识，便于下游把标签当作结构化数据处理。 |
| `fillColor` | `chart_series`、`chart_point`、`chart_legend_entry` | 填充颜色。对柱状图可理解为柱子填充色；对饼图可理解为切片颜色；对系列图例项可理解为该系列的面填充颜色。 |
| `lineColor` | `chart_series`、`chart_point`、`chart_legend_entry` | 线条颜色。对折线图通常是折线颜色；对饼图切片通常是切片边框颜色；对柱状图可能是柱子边框颜色。 |
| `textColor` | `chart_legend` | 文本颜色。目前只在图例文本属性中解析到默认文字颜色时输出。 |

颜色值可能是 `#RRGGBB` 形式的实际 RGB，也可能是 `accent1`、`tx1`、`bg1` 这类 Office 主题色名称，或预设/系统颜色名。当前工程不会把主题色进一步换算成最终 RGB。

## `chart` 属性

| 属性 | 说明 |
|---|---|
| `relationshipId` | 当前文档部件中指向图表 XML 部件的关系 ID，例如 `rId4`。它需要结合 `.rels` 关系文件才能找到实际图表路径。 |
| `target` | 关系 ID 解析后的图表 XML 路径或外部目标，例如 `word/charts/chart1.xml`、`ppt/charts/chart1.xml`、`xl/charts/chart1.xml`。如果目标缺失、外部不可读或包内不存在，图表只会输出引用信息，不会展开内部结构。 |
| `chartType` | 图表类型，来自 OOXML `plotArea` 下第一个以 `Chart` 结尾的节点名，例如 `pieChart`、`lineChart`、`barChart`、`bar3DChart`、`radarChart`。组合图目前只取第一个图表类型。 |
| `title` | 图表标题。工程会优先读取标题中的富文本，其次读取缓存值，再其次读取标题公式引用。没有显式标题时为空。 |
| `anchorType` | 图表锚定/承载方式。常见值包括 Word 的 `inline`、`anchor`，PowerPoint 的 `graphicFrame`，Excel 的 `twoCellAnchor`、`oneCellAnchor`、`absoluteAnchor`。它决定位置尺寸属性的解释方式。 |
| `xPt` | 图表横向位置或偏移，单位为 point。1 inch = 72 point。具体相对哪里取决于 `anchorType` 和源文件锚定方式。 |
| `yPt` | 图表纵向位置或偏移，单位为 point。具体相对哪里取决于 `anchorType` 和源文件锚定方式。 |
| `widthPt` | 图表外框宽度，单位为 point。 |
| `heightPt` | 图表外框高度，单位为 point。 |
| `horizontalRelativeFrom` | Word 浮动图表的水平参照对象，例如页面、页边距、列等。只有源 XML 使用浮动锚并提供该信息时才输出。 |
| `horizontalAlign` | Word 浮动图表相对水平参照对象的对齐方式，例如左对齐、居中、右对齐。 |
| `verticalRelativeFrom` | Word 浮动图表的垂直参照对象，例如页面、段落、行等。 |
| `verticalAlign` | Word 浮动图表相对垂直参照对象的对齐方式。 |
| `fromColumn` | Excel 图表锚点起始单元格列号，保留 OOXML 中的原始列索引。 |
| `fromRow` | Excel 图表锚点起始单元格行号，保留 OOXML 中的原始行索引。 |
| `fromColumnOffsetPt` | Excel 起始锚点相对起始列的横向偏移，单位为 point。 |
| `fromRowOffsetPt` | Excel 起始锚点相对起始行的纵向偏移，单位为 point。 |
| `toColumn` | Excel 图表锚点结束单元格列号，保留 OOXML 中的原始列索引。 |
| `toRow` | Excel 图表锚点结束单元格行号，保留 OOXML 中的原始行索引。 |
| `toColumnOffsetPt` | Excel 结束锚点相对结束列的横向偏移，单位为 point。 |
| `toRowOffsetPt` | Excel 结束锚点相对结束行的纵向偏移，单位为 point。 |

## `chart_source` 属性

| 属性 | 说明 |
|---|---|
| `relationshipId` | 图表 XML 内部指向数据源的关系 ID，通常来自 `externalData`。 |
| `target` | 数据源目标。可能是包内嵌入的 xlsx，例如 `word/embeddings/Workbook1.xlsx`；也可能是外部文件 URL 或本地文件 URI。 |
| `relationshipType` | OOXML 关系类型。内嵌工作簿常见为 package 关系，外部 OLE/工作簿可能是 oleObject 或 externalLink 相关关系。 |
| `targetMode` | 关系目标模式。常见值是 `External`，表示目标在当前 Office 包外部；为空通常表示包内关系。 |
| `type` | 工程归纳后的数据源类型。`embedded_xlsx` 表示包内嵌入的 xlsx 且可继续展开；`external` 表示外部 URL；`package_part` 表示包内部件或未归类的包内目标。 |

## 图表数据表属性

图表数据表复用 xlsx 表格解析逻辑，只有在 `chart_source` 的 `type="embedded_xlsx"` 且内嵌工作簿可读取时才会出现。

| 标签/属性 | 说明 |
|---|---|
| `table.sheet` | 内嵌工作簿中的工作表名称。 |
| `table.part` | 内嵌工作簿中工作表 XML 的包内路径。 |
| `table.role` | 表格用途。作为图表数据源输出时固定为 `chart_data`。 |
| `table_row.index` | 行号，来自工作表 XML 的行索引。 |
| `table_cell.ref` | 单元格地址，例如 `A1`、`B2`。 |
| `table_cell.alignment` | 单元格水平对齐方式。 |
| `table_cell.verticalAlignment` | 单元格垂直对齐方式。 |
| `table_cell.indent` | 单元格缩进。 |
| `table_cell.rowspan` | 表格输出层面的行跨度。普通单元格为 `1`；合并区域被覆盖的单元格为 `0`。 |
| `table_cell.colspan` | 表格输出层面的列跨度。普通单元格为 `1`；合并区域被覆盖的单元格为 `0`。 |
| `table_cell.mergedRef` | 合并单元格区域，例如 `A1:B2`。 |
| `table_cell.merged` | 合并状态。`origin` 表示合并区域左上角主单元格；`covered` 表示被合并覆盖的单元格。 |
| `table_cell.mergeOriginRow` | 对 `covered` 单元格，指向合并区域主单元格所在行。 |
| `table_cell.mergeOriginColumn` | 对 `covered` 单元格，指向合并区域主单元格所在列。 |

## `chart_legend` 属性

| 属性 | 说明 |
|---|---|
| `position` | 图例位置，来自 OOXML `legendPos`。常见值包括 `t` 顶部、`b` 底部、`l` 左侧、`r` 右侧、`tr` 右上。 |
| `overlay` | 图例是否覆盖图表绘图区。`true` 表示允许图例压在绘图区上；`false` 表示图表布局通常会为图例留出空间。 |
| `deleted` | 图例是否被标记为删除。 |
| `textColor` | 图例默认文字颜色。可能是 RGB，也可能是主题色名称。 |
| `layoutTarget` | 手动布局的参照区域，来自 `manualLayout/layoutTarget`。 |
| `xMode` | 手动布局 x 坐标解释方式，来自 OOXML 原值。 |
| `yMode` | 手动布局 y 坐标解释方式，来自 OOXML 原值。 |
| `x` | 手动布局横向位置。通常是相对布局区域的比例值，当前工程保留原始字符串。 |
| `y` | 手动布局纵向位置。通常是相对布局区域的比例值，当前工程保留原始字符串。 |
| `w` | 手动布局宽度。通常是相对布局区域的比例值，当前工程保留原始字符串。 |
| `h` | 手动布局高度。通常是相对布局区域的比例值，当前工程保留原始字符串。 |

## `chart_legend_entry` 属性

| 属性 | 说明 |
|---|---|
| `index` | 工程输出图例项时生成的顺序号，从 `0` 开始。 |
| `source` | 图例项来源。`series` 表示该图例项对应一个系列；`point` 表示该图例项对应一个数据点。饼图和圆环图通常使用 `point`。 |
| `seriesIndex` | 图例项所属系列的索引，来自系列的 `idx`。 |
| `pointIndex` | 图例项对应的数据点索引。只有 `source="point"` 时通常会出现。 |
| `label` | 图例项显示文本。对系列图例通常是系列名称；对饼图切片图例通常是分类名。 |
| `deleted` | 该图例项是否被标记为删除。 |
| `fillColor` | 该图例项对应系列或数据点的填充颜色。 |
| `lineColor` | 该图例项对应系列或数据点的线条颜色。 |

## `chart_axis` 属性

| 属性 | 说明 |
|---|---|
| `type` | 坐标轴类型。`catAx` 是类别轴，通常承载分类名称；`valAx` 是数值轴，承载数值刻度；`dateAx` 是日期轴；`serAx` 是系列轴或 3D 图表中的深度轴。 |
| `id` | 坐标轴 ID。图表内部用它标识一条轴。 |
| `position` | 坐标轴位置，来自 `axPos`。常见值包括 `b` 底部、`l` 左侧、`r` 右侧、`t` 顶部。 |
| `title` | 坐标轴标题文本。 |
| `crossAxis` | 与当前轴交叉的另一条轴 ID。 |
| `crosses` | 当前轴与另一条轴的交叉方式，例如自动在零点交叉。 |
| `tickLabelPosition` | 刻度标签位置，例如贴近坐标轴、顶部/底部或不显示。 |
| `majorTickMark` | 主刻度线样式，例如无刻度、内侧、外侧、交叉。 |
| `minorTickMark` | 次刻度线样式。 |
| `orientation` | 坐标轴刻度方向。常见 `minMax` 表示从最小到最大，`maxMin` 表示反向。 |
| `min` | 坐标轴最小值。只有手动设置最小值时通常才出现。 |
| `max` | 坐标轴最大值。只有手动设置最大值时通常才出现。 |
| `majorUnit` | 主刻度单位，例如每隔多少数值显示一个主刻度。 |
| `minorUnit` | 次刻度单位。 |
| `numberFormat` | 坐标轴刻度数字格式，例如 `General`、`0.00%`。 |
| `sourceLinked` | 数字格式是否链接到源数据格式。`1`/`true` 通常表示跟随源数据格式。 |
| `majorGridlines` | 是否存在主网格线。当前只要 XML 中出现 `majorGridlines` 就输出 `true`。 |
| `minorGridlines` | 是否存在次网格线。当前只要 XML 中出现 `minorGridlines` 就输出 `true`。 |

## `chart_data_labels` 属性

| 属性 | 说明 |
|---|---|
| `scope` | 数据标签设置作用范围。`chart` 表示图表级默认设置；`series` 表示某个系列自己的设置。 |
| `seriesIndex` | 当 `scope="series"` 时，表示该设置作用于哪个系列。 |
| `position` | 数据标签位置，例如在数据点内部、外部、顶部、底部等。 |
| `showLegendKey` | 标签中是否显示图例键，也就是颜色/线条的小标识。 |
| `showValue` | 标签中是否显示数据值。 |
| `showCategoryName` | 标签中是否显示分类名称。 |
| `showSeriesName` | 标签中是否显示系列名称。 |
| `showPercent` | 标签中是否显示百分比，常见于饼图、圆环图。 |
| `showBubbleSize` | 标签中是否显示气泡大小，主要用于气泡图。 |
| `showLeaderLines` | 是否显示引导线。饼图标签放在切片外部时常见。 |
| `separator` | 多个标签字段之间的分隔符，例如换行、逗号、空格等。 |
| `numberFormat` | 数据标签数值格式，例如 `General`、`0.00%`。 |
| `sourceLinked` | 标签数字格式是否跟随源数据格式。 |

## `chart_series` 属性

`chart_series` 是理解图表数据最关键的元素。它表示“用同一种图形样式绘制的一组数据点”。例如：

- 折线图里，`chart_series` 通常对应一条折线。
- 柱状图里，`chart_series` 通常对应同一种颜色的一组柱子。
- 饼图里，通常只有一个 `chart_series`，系列中的每个 `chart_point` 对应一个饼图切片。
- 多系列图表中，多个 `chart_series` 共享同一组分类轴，但各自有不同的数值范围。

| 属性 | 说明 |
|---|---|
| `index` | 系列索引，来自 OOXML 的 `idx`。它是源文件中的系列标识，不一定等同于视觉绘制顺序。 |
| `name` | 系列名称。图例中显示的系列名通常来自这里。 |
| `fillColor` | 系列填充颜色。对面积图、柱状图、饼图等更有意义；折线图不一定有填充色。 |
| `lineColor` | 系列线条颜色。对折线图通常就是折线颜色；对柱状图/饼图可能表示边框颜色。 |
| `nameRef` | 系列名称所在的源数据单元格引用，例如 `Sheet1!$B$1`。 |
| `categoriesRef` | 分类名称所在的数据区域引用，例如 `Sheet1!$A$2:$A$5`。分类通常是横轴标签、饼图切片名称等。 |
| `categoryCount` | 图表 XML 缓存中解析到的分类点数量。它统计的是缓存点数量，不会重新计算工作表区域。 |
| `valuesRef` | 系列数值所在的数据区域引用，例如 `Sheet1!$B$2:$B$5`。 |
| `valueCount` | 图表 XML 缓存中解析到的数值点数量。它统计的是缓存点数量，不会重新计算工作表区域。 |

## `chart_point` 属性

| 属性 | 说明 |
|---|---|
| `index` | 数据点索引。优先使用分类缓存点的 `idx`，否则使用数值缓存点的 `idx`，再否则使用工程生成的顺序号。 |
| `category` | 数据点的分类名称。折线图/柱状图中通常是横轴类别；饼图中通常是切片名称。 |
| `value` | 数据点的数值。当前读取图表 XML 中缓存的值，不会计算公式，也不会打开外部工作簿重新取值。 |
| `fillColor` | 该数据点单独设置的填充颜色。饼图切片经常有点级颜色。 |
| `lineColor` | 该数据点单独设置的线条颜色或边框颜色。 |

## 解析边界

当前图表解析是静态 OOXML 提取，不是 Office 渲染引擎，因此有以下边界：

- 不渲染图表图片，也不计算图例、标签和坐标轴的最终视觉碰撞布局。
- `chartType` 对组合图只取 `plotArea` 下第一个图表类型。
- 当前数据点主要读取 `cat`/`val` 缓存结构；散点图、气泡图、股票图等使用 `xVal`、`yVal`、`bubbleSize`、`open/high/low/close` 的结构还没有完整展开。
- `categoryCount` 和 `valueCount` 来自图表 XML 中的缓存点数量，不保证等同于源工作表当前可计算出的区域大小。
- 外部数据源只输出关系和目标路径，不会联网或访问外部文件读取实际数据。
- 主题色目前保留为主题名，不解析主题文件后换算成最终 RGB。
