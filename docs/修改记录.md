# 修改记录

## 2026-05-15

本次在 `OfficeOutline` 当前目录下新增了一个 C++17 命令行解析工具 `office-outline`。

### 新增内容

- 新增 `src/xml.hpp`、`src/xml.cpp`：实现轻量 XML 树解析、命名空间本地名匹配、文本和属性转义。
- 新增 `src/office_outline.cpp`：实现 OOXML 包解压、关系文件解析，以及 `.docx`、`.xlsx`、`.pptx` 到 Markdown 标签的转换。
- 新增 `Makefile`：提供 `make` 和 `make test-docx`。
- 新增 `scripts/test_docx.sh`：使用 `corpus/北大博士研究生毕业论文格式.docx` 做回归测试。
- 新增 `examples/北大博士研究生毕业论文格式.md`：由样例 docx 生成的 Markdown 输出。
- 新增 `.gitignore`：排除 `core/`、构建二进制和目标文件，避免把 LibreOffice 大工程纳入本仓库提交。
- 新增 `README.md`：记录构建、使用、输出标签、测试方式和 LibreOffice 参考路径。

### 解析能力

- Word `.docx`：段落、文本运行、纯文本、表格、单元格、绘图对象、图片、形状、超链接、公式、文本框内容。
- Excel `.xlsx`：工作表、行、单元格、共享字符串、公式、单元格超链接、绘图对象和基础字体样式。
- PowerPoint `.pptx`：幻灯片、形状、文本框、段落、文本运行、图片、表格和基础 DrawingML 字体样式。

### 输出格式

输出为 Markdown 文件中的结构化标签。每个元素都带有 `tag` 属性；文本相关标签包含：

- `fontName`
- `fontSize`
- `fontColor`
- `bold`
- `italic`
- `underline`

### 验证结果

已执行：

```bash
make
make test-docx
```

测试生成的样例输出为：

```text
examples/北大博士研究生毕业论文格式.md
```

该文件包含段落、文本运行、纯文本、表格、表格单元格、绘图对象、超链接、公式、图片和形状标签，并包含字体格式属性。
