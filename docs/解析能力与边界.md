# OfficeOutline 解析能力与边界

更新时间：2026-05-18

本文基于当前 `src/office_outline.cpp` 的实际输出逻辑整理。OfficeOutline 的输出是 Markdown 文件中的 XML/HTML 风格标签：每个结构元素都带 `tag="..."` 属性；有子元素时使用成对标签，无子元素时使用自闭合标签；文本内容会做 Markdown/XML 转义。

示例风格：

```xml
<paragraph tag="paragraph" fontName="宋体" fontSize="12" fontColor="" bold="false" italic="false" underline="none" alignment="center">
  <text_run tag="text_run" fontName="宋体" fontSize="12" fontColor="" bold="false" italic="false" underline="none">
    <plain_text tag="plain_text" fontName="宋体" fontSize="12" fontColor="" bold="false" italic="false" underline="none">示例文本</plain_text>
  </text_run>
</paragraph>
```

## 当前支持的标签、属性和示例

通用约定：

- `fontName`、`fontSize`、`fontColor`、`bold`、`italic`、`underline` 是文本格式属性，出现在 `paragraph`、`text_run`、`plain_text`、`hyperlink`、`text_box`、`table`、`table_cell` 等格式化标签上。
- 属性值为空时通常不会输出；文本格式属性例外，会输出为空字符串或默认值。
- `docx`、`pptx`、`xlsx` 都通过 OOXML 包关系解析图片、图表、超链接等目标路径。

| 文件类型 | 标签 | 标签风格 | 当前支持的属性 | 示例 |
|---|---|---|---|---|
| 全部 | `document` | 根容器 | `tag`、`type`、`source` | `<document tag="document" type="docx" source="corpus/a.docx">` |
| docx、pptx | `part` | 文档部件/幻灯片容器 | docx: `path`；pptx: `kind`、`name`、`path` | `<part tag="part" kind="slide" name="slide1" path="ppt/slides/slide1.xml">` |
| docx、pptx | `paragraph` | 段落容器 | 文本格式属性；docx: `styleId`、`styleName`、`alignment`、`indentLeft`、`indentRight`、`indentFirstLine`、`indentHanging`、`listId`、`listLevel`、`listType`、`listFormat`、`listText`；pptx/DrawingML: `alignment`、`marginLeft`、`marginRight`、`indent`、`listLevel`、`listType`、`bulletChar`、`numberingType`、`numberingStart` | `<paragraph tag="paragraph" fontName="宋体" fontSize="12" fontColor="" bold="false" italic="false" underline="none" alignment="justify" indentFirstLine="21" listId="3" listLevel="0" listType="numbered">` |
| docx、pptx | `text_run` | 段落内文本片段 | 文本格式属性 | `<text_run tag="text_run" fontName="Arial" fontSize="11" fontColor="#000000" bold="true" italic="false" underline="none">` |
| docx、pptx、xlsx | `plain_text` | 文本叶子节点；符号也可能用空标签表达 | 文本格式属性；docx 符号额外支持 `font`、`char` | `<plain_text tag="plain_text" fontName="宋体" fontSize="12" fontColor="" bold="false" italic="false" underline="none">正文</plain_text>` |
| docx、xlsx | `hyperlink` | 超链接容器 | 文本格式属性；docx: `relationshipId`、`target`、`anchor`；xlsx: `target`；pptx 文本链接: `relationshipId`、`target` | `<hyperlink tag="hyperlink" fontName="" fontSize="" fontColor="" bold="false" italic="false" underline="none" relationshipId="rId5" target="https://example.com">` |
| docx、pptx | `line_break` | 自闭合换行标签 | `tag` | `<line_break tag="line_break" />` |
| docx、pptx、xlsx | `table` | 表格容器 | 文本格式属性；xlsx 额外支持 `sheet`、`part` | `<table tag="table" sheet="Sheet1" part="xl/worksheets/sheet1.xml">` |
| docx、pptx、xlsx | `table_row` | 表格行容器 | `tag`、`index` | `<table_row tag="table_row" index="1">` |
| docx、pptx、xlsx | `table_cell` | 表格单元格容器 | 文本格式属性；docx/pptx: `column`、`rowspan`、`colspan`、`merged`、`vMerge`、`hMerge`、`mergeOriginRow`、`mergeOriginColumn`；xlsx: `ref`、`alignment`、`verticalAlignment`、`indent`、`rowspan`、`colspan`、`mergedRef`、`merged`、`mergeOriginRow`、`mergeOriginColumn` | `<table_cell tag="table_cell" ref="A24" alignment="center" verticalAlignment="center" mergedRef="A24:B30" merged="origin" rowspan="7" colspan="2">` |
| docx、pptx、xlsx | `drawing_object` | 绘图对象容器 | docx/pptx 图片: `kind`；xlsx 绘图部件: `part` | `<drawing_object tag="drawing_object" kind="picture">` |
| docx、pptx、xlsx | `image` | 图片叶子节点 | `relationshipId`、`target`、`objectId`、`objectName`、`description`、`title`、`contentType`、`dataAvailable`、`sizeBytes` | `<image tag="image" relationshipId="rId9" target="word/media/image1.png" objectId="3" objectName="图片 3" description="校徽" contentType="image/png" dataAvailable="true" sizeBytes="39100" />` |
| docx、pptx、xlsx | `shape` | 形状容器或叶子节点 | `sourceElement`、`id`、`name`、`objectId`、`objectName`、`description`、`title`、`presetGeometry` | `<shape tag="shape" sourceElement="p:sp" id="4" name="矩形 4" presetGeometry="rect">` |
| docx、pptx、xlsx | `text_box` | 形状内文本框容器 | 文本格式属性 | `<text_box tag="text_box" fontName="" fontSize="" fontColor="" bold="false" italic="false" underline="none">` |
| docx、pptx、xlsx | `chart` | 图表引用或图表容器 | `relationshipId`、`target`、`chartType`、`title` | `<chart tag="chart" relationshipId="rId1" target="xl/charts/chart1.xml" chartType="bar3DChart" title="Sales">` |
| docx、pptx、xlsx | `chart_series` | 图表系列叶子节点 | `index`、`name`、`nameRef`、`categoriesRef`、`categoryCount`、`valuesRef`、`valueCount` | `<chart_series tag="chart_series" index="0" name="Revenue" nameRef="Sheet1!$B$1" categoriesRef="Sheet1!$A$2:$A$5" categoryCount="4" valuesRef="Sheet1!$B$2:$B$5" valueCount="4" />` |
| docx | `formula` | Word 数学公式/字段公式文本 | `tag` | `<formula tag="formula">x+y</formula>` |
| xlsx | `formula` | 单元格公式文本 | `tag` | `<formula tag="formula">SUM(A1:A5)</formula>` |
| docx、pptx、xlsx | `bookmark` | 书签/命名区域标签 | docx: `action`、`id`、`name`、`columnFirst`、`columnLast`；xlsx defined name: `type`、`name`、`localSheetId`、`hidden`；pptx 泛化书签: `sourceElement`、`id`、`name`、`target` | `<bookmark tag="bookmark" action="start" id="5" name="_Toc123" />` |
| docx、pptx、xlsx | `revision` | 修订痕迹或修订部件摘要 | docx inline: `type`、`id`、`author`、`date`；OOXML 修订部件摘要: `part`、`element`、`id`、`author`、`date` | `<revision tag="revision" type="insert" id="1" author="Alice" date="2026-05-18T10:00:00Z">` |

## 按文件类型的能力说明

| 文件类型 | 当前可提取内容 | 主要入口和范围 | 备注 |
|---|---|---|---|
| `.docx` | 主文档、页眉、页脚、脚注、尾注中的段落、文本、表格、合并单元格、图片、形状、文本框、图表、超链接、公式、列表、书签、修订痕迹 | `word/document.xml`；`word/header*.xml`、`word/footer*.xml`、`word/footnotes.xml`、`word/endnotes.xml` | 列表会解析 `word/numbering.xml`；样式会解析 `word/styles.xml` 的基础字体格式 |
| `.pptx` | 每张幻灯片里的图片、形状、文本框、段落、文本、表格、合并单元格、图表、超链接、部分书签/修订部件摘要 | `ppt/presentation.xml` 关联到的 `ppt/slides/slide*.xml` | 当前不解析母版和版式继承样式，仅解析幻灯片自身 XML 中直接出现的对象 |
| `.xlsx` | 工作簿中的工作表、行、单元格、文本、公式、超链接、合并单元格、单元格字体/对齐、绘图对象、图片、形状、图表、命名区域、修订部件摘要 | `xl/workbook.xml` 关联到的 `xl/worksheets/sheet*.xml`；绘图关系指向的 `xl/drawings/*.xml` 和 `xl/charts/*.xml` | 单元格值依赖 OOXML 中已有缓存值或共享字符串；不计算公式 |

## 当前不支持但可以通过修改支持的标签和属性

这些能力在 OOXML 包内通常有对应 XML 或关系数据，当前只是没有实现或只做了摘要。通过扩展解析器、关系遍历和输出模型可以支持。

| 文件类型 | 可扩展标签/属性 | OOXML 来源 | 修改方向 | 预期示例 |
|---|---|---|---|---|
| docx | `comment` 标签；`commentRangeStart`、`commentRangeEnd`、`author`、`date`、评论正文 | `word/comments.xml`、`w:commentRangeStart`、`w:commentReference` | 增加评论关系解析和正文输出 | `<comment tag="comment" id="2" author="Alice" date="...">批注内容</comment>` |
| docx | `footnote_ref`、`endnote_ref` 引用位置属性 | `w:footnoteReference`、`w:endnoteReference` | 当前会解析脚注/尾注部件正文，但正文中的引用锚点可单独输出 | `<footnote_ref tag="footnote_ref" id="1" />` |
| docx | 更完整的段落样式属性：行距、段前段后、分页控制、边框、底纹 | `w:pPr` 中 `w:spacing`、`w:keepNext`、`w:pageBreakBefore`、`w:pBdr`、`w:shd` | 扩展 `ParagraphInfo` | `<paragraph ... spacingBefore="12" spacingAfter="6" lineSpacing="1.5">` |
| docx | 更完整的运行格式：删除线、上/下标、高亮、背景、字符间距、大小写 | `w:rPr` 中 `w:strike`、`w:vertAlign`、`w:highlight`、`w:shd`、`w:spacing`、`w:caps` | 扩展 `TextFormat` | `<text_run ... strike="true" highlight="yellow" verticalAlign="superscript">` |
| docx | 表格宽度、边框、底纹、行高、单元格垂直对齐 | `w:tblPr`、`w:trPr`、`w:tcPr` | 扩展表格、行、单元格属性解析 | `<table_cell ... width="120" verticalAlignment="center" fillColor="#EEEEEE">` |
| docx | 图片尺寸和位置 | `wp:extent`、`wp:positionH`、`wp:positionV`、`a:xfrm` | 在 `image` 或 `drawing_object` 上输出尺寸/锚定 | `<image ... widthPt="120" heightPt="80" wrap="square" />` |
| docx | 内容控件结构 | `w:sdt`、`w:sdtPr` | 当前只下钻内容；可输出控件标签和属性 | `<content_control tag="content_control" alias="客户名">...</content_control>` |
| pptx | 幻灯片备注、讲者备注 | `ppt/notesSlides/*.xml` | 解析 notesSlide 关系并输出 `notes` | `<notes tag="notes">讲者备注</notes>` |
| pptx | 幻灯片母版/版式继承属性 | `ppt/slideMasters/*.xml`、`ppt/slideLayouts/*.xml` | 合并 master/layout/slide 样式层级 | `<paragraph ... inheritedFrom="slideMaster1" fontSize="18">` |
| pptx | 动画、切换效果 | `p:timing`、`p:transition` | 增加动画和切换标签 | `<transition tag="transition" type="fade" duration="500" />` |
| pptx | 图层顺序、形状位置和尺寸 | `p:spTree` 顺序、`a:xfrm` | 输出 `zOrder`、`x`、`y`、`width`、`height` | `<shape ... zOrder="3" xPt="72" yPt="144" widthPt="200" heightPt="80">` |
| pptx | 形状填充、线条、阴影、透明度 | `a:solidFill`、`a:ln`、`a:effectLst` | 扩展 `shape` 视觉属性 | `<shape ... fillColor="#FF0000" lineColor="#333333" shadow="outer">` |
| pptx | 表格样式、边框、填充 | `a:tblPr`、`a:tcPr` | 扩展表格属性 | `<table_cell ... fillColor="#F5F5F5" borderBottom="#CCCCCC">` |
| xlsx | 公式计算结果状态、公式类型、数组公式范围 | `c/f` 的 `t`、`ref`、`si`、`ca` 等属性 | 扩展 `formula` 属性 | `<formula tag="formula" type="array" ref="A1:A10">SUM(B1:B10)</formula>` |
| xlsx | 数字格式、日期/百分比/货币格式 | `xl/styles.xml` 中 `numFmts`、`cellXfs` | 解析 number format 并转换显示值 | `<table_cell ... numberFormat="yyyy-mm-dd" valueType="date">` |
| xlsx | 单元格填充、边框、列宽、行高、隐藏状态 | `xl/styles.xml`、`cols`、`row` 属性 | 扩展样式、行列属性 | `<table_row ... height="18" hidden="true">` |

| xlsx | 工作表保护、工作簿保护 | `sheetProtection`、`workbookProtection` | 输出保护状态和算法摘要 | `<protection tag="protection" sheet="Sheet1" enabled="true" />` |
| 全部 | 关系类型、外部链接模式、原始 XML 路径 | `.rels` 文件 | 在 `hyperlink`、`image`、`chart` 上补 `relationshipType`、`targetMode` | `<image ... relationshipType=".../image" targetMode="Internal" />` |
| 全部 | 媒体导出文件 | `word/media`、`ppt/media`、`xl/media` | 当前只输出包内 target 和大小；可增加导出目录参数 | `<image ... exportedPath="assets/image1.png" />` |

## 当前提取方案无法支持或边界很硬的地方

当前方案是“解包 OOXML + 读取 XML + 按关系追踪部件”的静态提取，不是完整 Office 渲染引擎。以下能力要么源文件中没有信息，要么需要外部渲染/计算/识别系统，不能仅靠当前 XML 提取方案可靠完成。

| 边界 | 原因 | 影响 |
|---|---|---|
| 旧版二进制 Office：`.doc`、`.ppt`、`.xls` | 当前只处理 ZIP 结构的 OOXML；旧格式不是同一套 XML 包结构 | 不能直接解析；需要先转换为 OOXML 或引入二进制格式解析器 |
| 加密或密码保护文件 | `unzip` 无法读取加密包内容，XML 不可见 | 无法提取正文、图片、图表等内容 |
| 已被接受/拒绝的修订历史 | OOXML 中只保留当前状态和未接受的修订标记 | 文件里不存在的历史无法恢复 |
| 图片内容的语义描述 | 当前只能取 `descr/title/name` 等替代文本和媒体元数据；图片像素含义不在 XML 文本中 | 无法知道图片里实际画了什么；需要 OCR/视觉模型另行处理 |
| 图片二进制直接内嵌到 Markdown | 当前输出目标路径、大小和可用性，不输出 base64 | 不能单靠输出 Markdown 获得图片字节；可扩展为导出资产，但当前未做 |
| 精确分页、换行和版面复现 | Word/PPT/Excel 排版依赖字体、渲染引擎、页面设置和布局算法 | 输出适合结构理解，不等价于 PDF/Office 的视觉版面 |
| 公式实时计算 | 当前读取单元格公式文本和已有缓存值，不实现 Excel 计算引擎 | 没有缓存值或依赖复杂函数/外部链接时，不能得到可靠计算结果 |
| 宏和 VBA 语义 | VBA 存在于 `vbaProject.bin` 等二进制部件中，当前不解析 | 不能分析宏逻辑、按钮行为或自动化脚本 |
| 嵌入 OLE/ActiveX/native 对象内容 | 这些对象常是专有二进制或外部应用格式 | 当前最多能通过关系知道对象存在；无法语义化对象内部内容 |
| 外部链接目标内容 | OOXML 只保存 URL 或外部文件引用，目标内容不在包内 | 不联网、不访问外部文件时无法提取外部资源正文 |
| 丢失字体或平台相关渲染差异 | Office 渲染结果受字体替换、主题和应用版本影响 | 即使 XML 属性完整，也不能保证视觉尺寸和位置与 Office 完全一致 |
| 复杂图表渲染外观 | 当前解析图表类型、标题、系列和数据引用，不渲染图形 | 不能输出最终图表截图、坐标轴精确布局、图例碰撞处理等 |
| SmartArt、复杂 DrawingML 效果的完整语义 | SmartArt 和复杂效果需要专门模型和布局算法 | 当前可能只能提取部分形状/文本/图片关系，不能还原完整逻辑结构 |

## 结论

当前工程可以对 `.docx`、`.pptx`、`.xlsx` 做结构化信息提取，适合生成文档大纲、文本内容、表格结构、媒体引用、图表数据引用和基础样式信息。它的核心边界是：只提取 OOXML 包内明确存在的结构和属性，不负责 Office 级渲染、公式计算、图片语义识别、加密解密或旧版二进制格式解析。
